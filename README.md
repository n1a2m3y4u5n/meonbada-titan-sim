# 먼바다호 — 타이탄 액체 메테인 바다 탐사선 시뮬레이터

토성의 위성 타이탄의 액체 메테인 바다를 항행하는 유인 탐사선 「먼바다호」를 설계하고, 그 물리를 시뮬레이션합니다.

- 데모: https://remarkable-halva-5b73a1.netlify.app/
- 수상: 제6회 미래바다 아이디어 공모전 우수상 (선박해양플랜트연구소장상)

## 소개

타이탄은 태양계에서 지구를 제외하고 지표에 안정적인 액체가 있는 유일한 곳입니다.
다만 그 액체는 물이 아니라 액체 메테인·에테인이고, 중력·온도 조건도 지구와 전혀 다릅니다.
이 시뮬레이터는 그런 환경에서 선박이 어떻게 뜨고, 파도를 어떻게 타고, 저온에서 재료가 어떻게 버티는지를 계산해서 보여줍니다.

| | 지구 | 타이탄 |
|---|---|---|
| 액체 | 물 (약 1,000 kg/m³) | 액체 메테인 (약 450 kg/m³) |
| 중력 | 9.81 m/s² | 1.35 m/s² |
| 표면 온도 | 288 K | 94 K |

밀도가 절반이라 같은 배가 훨씬 깊이 잠기고, 중력이 7분의 1이라 파도의 거동도 달라집니다.

## 주요 기능

- 부력·흘수 계산: 선체 형상을 적분해 잠기는 깊이를 구합니다 (`buoyancy-netlify.js`)
- 파랑 모델: 타이탄 중력에서의 파장·주기 계산 (`waves-netlify.js`)
- 저온 재료 물성 모델 (`materials-netlify.js`)
- 대기·온도·밀도 등 환경 상수 모델 (`environment-netlify.js`)

## 기술

바닐라 JavaScript, HTML/CSS. 별도 빌드 과정 없는 정적 웹앱입니다.

## 실행 방법

```bash
# 저장소를 내려받은 뒤
open index.html
# 또는 로컬 서버로
python3 -m http.server
```

## 알아 둘 것

발표자료 한 곳에서 타이탄을 "목성의 위성"으로 적은 오류가 있습니다. 토성이 맞고, 공모전 제출 신청서 본문은 맞게 적었습니다.
