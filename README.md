# 먼바다호 — 타이탄 환경 선박 시뮬레이터

**토성의 위성 타이탄**의 액체 메테인 바다에서 항행하는 선박을 물리적으로 시뮬레이션합니다.

배포: **https://remarkable-halva-5b73a1.netlify.app/**

## 왜 타이탄인가

타이탄은 태양계에서 **지표에 안정적인 액체가 있는 유일한 곳**(지구 제외)입니다.
다만 그 액체가 물이 아니라 **액체 메테인·에테인**이고, 조건이 지구와 완전히 다릅니다.

| | 지구 | 타이탄 |
|---|---|---|
| 액체 | 물 (약 1,000 kg/m³) | 액체 메테인 (약 450 kg/m³) |
| 중력 | 9.81 m/s² | **1.35 m/s²** |
| 표면 온도 | 288 K | **94 K** |

**밀도가 절반이라 같은 배가 훨씬 깊이 잠기고**, 중력이 7분의 1이라 파도의 거동도 달라집니다.
저온에서 재료가 어떻게 버티는지도 함께 봐야 합니다.

## 무엇을 계산하나

| 파일 | 무엇 |
|---|---|
| `buoyancy-netlify.js` | 부력·흘수. 선체 형상을 적분해 잠기는 깊이를 구합니다 |
| `waves-netlify.js` | 파랑 모델. 타이탄 중력에서의 파장·주기 |
| `materials-netlify.js` | 저온 재료 물성 |
| `environment-netlify.js` | 대기·온도·밀도 등 환경 상수 |
| `physics.js` | 공통 물리 |
| `app-netlify.js` | 화면·상호작용 |

## 알아 둘 것

이 저장소는 **Netlify 배포본에서 복원한 것**입니다. 원 개발 저장소가 따로 있었다면 그쪽이 정본입니다.

발표자료 한 곳에서 타이탄을 **「목성의 위성」** 으로 적은 오류가 있습니다. **토성**이 맞고, 제출 신청서 본문은 맞게 적었습니다.
